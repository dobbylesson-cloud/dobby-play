管理員登入

管理社群已上架的遊戲、動畫、遠景、角色與畫板。只有白名單帳號可以修改。

  1. 到 GitHub 建立 Fine-grained token，只授權此 repository 的 Contents: Read and write。
  2. 把 token 貼到下面，按「驗證並登入」。系統會確認帳號是否為管理員。
  3. Token 只存在這台瀏覽器，不會寫進網站或 repo；換電腦要重新貼一次。

建立 token：GitHub → Settings → Developer settings → Fine-grained tokens （Repository access 選 dobbylesson-cloud/dobby-play，Permissions 的 Contents 設為 Read and write）

管理遊戲

先上架、後審核：可隨時下架或刪除不適合的內容。

這個分類目前沒有社群作品。

排序會直接改變網站上的顯示順序；「置頂」會排到該分類最前面；「下架」只是從網站列表隱藏，檔案仍保留；「刪除」會一併移除 repo 內的檔案與縮圖。
